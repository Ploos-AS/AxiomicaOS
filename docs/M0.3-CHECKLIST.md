# M0.3 completion checklist

M0.3 is complete only when every required gate below is satisfied.

- [x] freestanding m68k/68000 kernel build
- [x] Amiga machine BSP
- [x] AXAM kernel container
- [x] native 1024-byte boot block generator/checker
- [x] 880 KiB ADF generator/checker
- [x] static qualification gate
- [x] final m68k ELF has no runtime relocations or undefined symbols
- [x] `_axiomica_amiga_start` is pinned and audited at image offset zero
- [x] AXAM v1 uses relocatable `load=0` semantics
- [x] stage-0 allocates payload + private prefix + bootstrap stack from the AXAM header
- [x] stage-0 preserves the allocation base so partial-I/O failure frees the correct block
- [x] native runtime oracle
- [x] FS-UAE adapter and verifier
- [x] unattended Xvfb runner design
- [x] self-hosted runtime workflow
- [x] ROM-safe host contract/provisioning
- [ ] dedicated runtime host reports READY
- [ ] real FS-UAE A500/68000 boot reaches kernel-entry oracle
- [ ] real FS-UAE boot reaches halt oracle
- [ ] runtime evidence artifact retained
- [ ] M0.3 tagged/released

Do not mark the milestone complete from build success alone.


## Verified CI evidence

GitHub Actions run 36017021473 established the first complete M0.3 static qualification pass for the Amiga/68000 path. Run 36041953353 is the current verified static baseline after the header-first allocation, aligned bootstrap stack, entry-offset audit, and partial-I/O cleanup fixes. It reports a 372-byte stage-0 boot block, relocation/undefined-symbol-free ELF with entry offset zero, relocatable AXAM v1, and `M0.3 STATIC PASS`. Runtime qualification remains a separate gate and is not implied by these results.
