# M0.3 — Amiga boot bring-up

M0.3 separates qualification into two gates.

## Static gate

PASS requires:

- 880 KiB image
- valid Amiga boot signature
- valid boot-block checksum
- AXAM at byte 1024
- expected big-endian metadata
- 0x00100000 load address
- valid embedded payload checksum

Run:

    python3 tools/amiga/qualify-static.py build/m68k-amiga/axiomicaos-amiga.adf

## Runtime gate

Runtime PASS requires an A500/68000 emulator or hardware run that demonstrably reaches the AxiomicaOS kernel proof-of-life marker.

Therefore a static PASS must never be reported as an M0.3 runtime PASS.
